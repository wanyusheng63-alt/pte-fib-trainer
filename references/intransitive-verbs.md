# PTE FIB 高频不及物动词名单

> 来自 Chainsawman 笔记梳理。不及物动词做非谓语时**只有 v-ing / to do 两种形式，永远没有 v-ed**。

## 核心规则

一个动词是否及物，不看死记的标签，而看**主语能否直接发出这个动作并作用于后面的名词**。

判断公式：
- 动词 + 介词 + 名词 → 不及物用法（动作不直接作用于名词）
- 动词 + 名词（无介词）→ 及物用法（动作直接作用于名词）
- 同一个动词可能同时有及物和不及物用法（取决于语义）

## PTE 高频不及物动词

### 绝对不及物（PTE 考试中几乎永远不及物）

| 动词 | 常见搭配 | 注意事项 |
|------|----------|----------|
| arrive | arrive at/in | 绝不能直接跟宾语 |
| go | go to/into/through | |
| come | come to/from/into | come true 是固定搭配（系表） |
| happen | happen to | 无被动语态 |
| occur | occur to/in | 无被动语态 |
| exist | exist in/on | 无被动语态 |
| appear | appear to/in/on | 也可是系动词 |
| seem | seem to | 系动词 |
| look | look at/for/into | 也可是系动词 |
| remain | remain in/with | 也可是系动词 |
| stay | stay in/at/with | 也可是系动词 |
| lie | lie in/on/with | 不及物：躺/位于；及物 lay 是"放置" |
| rise | rise from/to | 不及物：上升；及物 raise 是"举起" |
| fall | fall from/into/to | |
| die | die of/from | |
| live | live in/on/with | |
| sleep | sleep in/on | |
| wait | wait for | |
| listen | listen to | 注意：hear 是及物 |
| rely | rely on | |
| depend | depend on | |
| consist | consist of | 无被动语态 |
| belong | belong to | 无被动语态 |
| lead | lead to | 及物 lead=领导；不及物 lead to=导致 |

### 半及物（PTE中需根据语义判断）

| 动词 | 及物用法 | 不及物用法 |
|------|----------|------------|
| run | run a company (经营) | run in the park (跑步) |
| grow | grow plants (种植) | grow up (成长) |
| change | change the world (改变) | change from A to B (变化) |
| develop | develop a theory (发展) | develop into (演变成) |
| begin | begin the meeting (开始) | begin with (以...开始) |
| continue | continue the work (继续) | continue with (接着...) |
| move | move the table (移动) | move to (搬到) |
| return | return the book (归还) | return to (回到) |
| turn | turn the page (翻) | turn into/left (变成/转弯) |

## 使用流程

遇到一个动词挖空，且选项中有 v-ed 形式时：

1. 查这个动词是否在**绝对不及物**名单里 → 在 → v-ed 直接排除
2. 查是否在**半及物**名单里 → 在 → 看句子中动词后是否有介词
   - 有介词 → 不及物用法 → v-ed 排除
   - 无介词 + 有宾语 → 及物用法 → 可保留 v-ed（被动）
3. 都不在 → 默认及物 → 做主语-动作关系判断

## 记忆口诀

"不及物非谓语，ved 不存在；看到介词后面接，不及物的可能大。"

## 常见 ving 形容词（来自真题）

> 这些词在选项中非常容易和真正的非谓语动词混淆。判断方法：看空后面有没有宾语/介词。如果后面直接跟名词（无介词）且在名词前修饰该名词 → ving 形容词。

| 动词 | 用法提示 |
|------|----------|
| Demanding | 形容词 = 要求高的 |
| Surprising | 形容词 = 令人惊讶的 |
| intriguing | 形容词 = 有趣的（类似 interesting） |
| growing | 可做 adj ("增长的") 也可做非谓语 |
| increasing | 可做 adj ("增加的") 也可做非谓语 |
| leading | 可做 adj ("领先的") 也可做非谓语 |
| existing | 可做 adj ("现有的") 也可做非谓语 |
| remaining | 可做 adj ("剩余的") 也可做非谓语 |
