# PTE FIB 信号词策略

> 词汇题遇到生词时，不要慌。用信号词推断词义方向和情感色彩。

## 一、转折信号词

**功能**：前后语义方向相反。认识一边就能推另一边。

| 信号词 | 强度 | 例句模式 |
|--------|------|----------|
| but | 强转折 | A is X, but B is [opposite] |
| however | 强转折 | A is X. However, B is [opposite] |
| yet | 强转折 | A is X, yet B is [opposite] |
| although / though | 让步 | Although A is X, B is [opposite] |
| whereas / while | 对比 | A is X, whereas B is [opposite] |
| despite / in spite of | 让步 | Despite X, [opposite result] |
| on the contrary | 对比 | 直接否定前文 |
| rather than | 取舍 | A rather than B → 要A不要B |
| instead of | 替代 | A instead of B → A替代B |
| nevertheless / nonetheless | 转折 | 尽管如此，但是... |

### 使用策略

```
原文：The policy was intended to boost employment; 
      however, it inadvertently (_______) job losses.

不认识 inadvertently → 看 however → 前后相反
前半句：政策意在"促进就业"
however后 → 应该跟"促进就业"相反
→ 空格应该是"导致/引发"之类的负面动词
```

## 二、并列信号词

**功能**：前后词性、色彩、程度一致。

| 信号词 | 强度 | 提示 |
|--------|------|------|
| and | 并列 | 前后同等 |
| or | 选择 | 前后同类 |
| as well as | 附加 | 倾向于前者 |
| not only...but also | 递进 | 后者更强 |
| both...and | 双选 | 两者都是 |
| neither...nor | 双否 | 两者都不是 |
| similarly | 相似 | 前后类似 |
| likewise | 相似 | 前后类似 |

### 使用策略

```
原文：The research was both (_______) and groundbreaking.

不认识 groundbreaking → 看 and → 前后色彩一致
groundbreaking = 开创性的（正面）
→ 空格应该也是正面形容词
→ 排除负面选项
```

## 三、因果信号词

**功能**：用逻辑链推断词义方向。

| 信号词 | 方向 | 例句模式 |
|--------|------|----------|
| because / since / as | 因←果 | Because X, Y |
| therefore / thus / hence | 因→果 | X, therefore Y |
| consequently / as a result | 因→果 | X, consequently Y |
| lead to / result in | 因→果 | X leads to Y |
| result from | 果←因 | X results from Y |
| due to / owing to | 因←果 | Y is due to X |
| so...that | 程度→结果 | so X that Y |

### 使用策略

```
原文：The drought was so severe that agricultural 
      output (_______) dramatically.

so severe that → 程度到了产生结果
干旱严重 → 结果应该是农业产出"下降/减少"
→ 排除"上升/增长"类词汇
```

## 四、解释/重述信号词

**功能**：后面会用更简单的话重述前面的意思。

| 信号词 | 提示 |
|--------|------|
| that is / i.e. | 即，也就是说 |
| in other words | 换句话说 |
| namely | 也就是 |
| put simply | 简单来说 |
| or rather | 更准确地说 |
| to be precise | 准确地说 |

## 五、递进信号词

**功能**：后面的意思比前面更强。

| 信号词 | 方向 |
|--------|------|
| moreover / furthermore | 正向递进 |
| indeed / in fact | 正向递进 |
| even | 程度递进 |
| what's more | 正向递进 |
| above all | 最重要 |

## 六、情感色彩锚定

当信号词不够明显时，用上下文情感判断：

1. **看主语和宾语的情感色彩**
   - breakthrough, progress, innovation → 正面语境
   - crisis, decline, threat → 负面语境
   - research, study, analysis → 中性/学术

2. **看修饰语的强度**
   - slightly / marginally → 轻度变化
   - significantly / dramatically → 剧烈变化
   - completely / entirely → 完全变化

3. **一次性排除情感色彩不一致的选项**
   - 正面语境 → 排除所有负面词
   - 负面语境 → 排除所有正面词

## 实战优先级

做题时按以下顺序尝试：

1. 先找明确的信号词（转折/并列/因果）
2. 没有信号词 → 看主语宾语的情感色彩
3. 还判断不了 → 看修饰语的强度和方向
4. 还剩下2个选项 → 只能靠词汇量（这也是为什么精读积累不能丢）

## despite / however / although 的区别（高频考点）

> 来自 Chainsawman。这三个词在 FIB 中极易混淆。

| 词 | 词性 | 后接什么 | 例句结构 |
|----|------|----------|----------|
| **despite** | 介词 | **名词/名词短语/ving** | Despite [n], 句子 |
| **although** | 连词 | **完整句子（主+谓）** | Although [句子], 句子 |
| **however** | 连接副词 | **另起一句**（前面分号或句号） | 句子; however, 句子 |

**记忆方法**：
- despite = 介词 → 介词后面只能跟名词 → "despite + n"
- although = 连词 → 连词后面跟完整句子 → "although + S + V"
- however = 副词 → 不连接句子，只是插入 → "分号 + however + 逗号 + 句子"

**真题区分**：
```
(_______) its importance, the topic remains understudied.
→ 空格后是 its importance（名词短语，无谓语动词）
→ 填 despite（介词 + 名词短语）

(_______) the topic is important, it remains understudied.
→ 空格后是 the topic is important（完整句子，有主谓）
→ 填 although（连词 + 完整句子）
```
